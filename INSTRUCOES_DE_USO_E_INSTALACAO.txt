================================================================================
🚗 GUIA DE INSTALAÇÃO E USO: CONTROLE DE FLUXO VIÁRIO
================================================================================

Este pacote contém o sistema automatizado de monitoramento e auditoria periódica
de fluxos em radares de trânsito viário, com integração automática ao Google Sheets.

--------------------------------------------------------------------------------
1. FORMAS DE EXECUTAR O SISTEMA (ESCOLHA A SUA PREFERIDA)
--------------------------------------------------------------------------------

🔹 OPÇÃO 1: EXECUTÁVEL STANDALONE (.EXE) — SEM PRECISAR DE PYTHON INSTALADO!
   • Na pasta 'dist/ControleFluxoViario/', existe o arquivo:
     👉 ControleFluxoViario.exe
   • O usuário da empresa NÃO precisa ter Python instalado. Basta dar 2 cliques
     no 'Executar_Monitoramento.bat' ou direto no 'ControleFluxoViario.exe'.

🔹 OPÇÃO 2: EXECUÇÃO VIA PYTHON / ATALHO .BAT
   • Tendo o Python 3.10+ instalado no computador, basta dar 2 cliques em:
     👉 Executar_Monitoramento.bat
   • O script cria o ambiente isolado (venv) e instala os pacotes automaticamente.

🔹 OPÇÃO 3: NUVEM SERVERLESS (GOOGLE CLOUD SCHEDULER / GITHUB ACTIONS)
   • Roda 100% sozinho na nuvem às 07:50 e 13:30 sem precisar de computador ligado.
   • Veja o guia completo em: 'CONFIGURACAO_GOOGLE_CLOUD_SCHEDULER.md'.

--------------------------------------------------------------------------------
2. CONFIGURAÇÃO INICIAL (FEITA APENAS 1 VEZ)
--------------------------------------------------------------------------------
Passo 1: Extraia os arquivos em um local fixo no computador (ex: C:\Controle-Fluxo).

Passo 2: Crie o arquivo de configurações '.env':
         - Faça uma cópia do arquivo '.env.example' e renomeie para '.env'.
         - Abra o '.env' com o Bloco de Notas e preencha:
           • SITE_USERNAME: Seu usuário de acesso ao portal viário.
           • SITE_PASSWORD: Sua senha de acesso ao portal viário.
           • GOOGLE_SHEET_ID: O ID da planilha compartilhada do Google Sheets.

Passo 3: Chave do Google Sheets:
         - Coloque o arquivo 'service_account.json' na raiz da pasta.

--------------------------------------------------------------------------------
3. COMO RESOLVER CAPTCHA / RENOVAR SESSÃO (SE NECESSÁRIO)
--------------------------------------------------------------------------------
* Se o portal exigir resolução de Captcha para entrar:
  👉 Dê um duplo clique no arquivo: "Resolver_Captcha_Login.bat"
     (ou em 'dist/ResolverCaptcha/ResolverCaptcha.exe')

  1. O navegador Google Chrome vai abrir na sua tela.
  2. Resolva o Captcha na tela com o mouse e clique em "Entrar".
  3. O script salvará os cookies no arquivo 'session_state.json'.
  4. Pronto! As próximas execuções diárias entrarão direto sem pedir Captcha.

--------------------------------------------------------------------------------
4. COMO AGENDAR NO WINDOWS (AGENDADOR DE TAREFAS / TASK SCHEDULER)
--------------------------------------------------------------------------------
1. Abra o menu Iniciar do Windows e digite "Agendador de Tarefas".
2. Clique em "Criar Tarefa Básica".
3. Nome: "Monitoramento Radares - Manhã", Disparador: Diariamente às 07:50.
4. Ação: "Iniciar um programa" -> Selecione o 'Executar_Monitoramento.bat'.
5. Repita o processo criando outra tarefa para as 13:30.
